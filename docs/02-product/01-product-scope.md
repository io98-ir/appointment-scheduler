# محصول: دامنه، نقش‌ها و مراحل

> نام محصول هنوز انتخاب نشده. در کد از **نام کاری `Vaqtyar`** استفاده می‌شود که با یک اسکریپت قابل تعویض است. نام نمایشی در تنظیمات White-label در هر زمان عوض می‌شود. ر.ک. [ADR-000](../03-architecture/05-decisions.md).

## 1. چشم‌انداز
یک **افزونه نوبت‌دهی عمومی** برای وردپرس که الهام‌گرفته از Bookly، Booknetic (+Custom Duration)، نوبت‌پلاس، نوبت‌نگار و Medino است، ولی:
- **درست‌تر** است: Double booking غیرممکن است.
- **ترکیب‌پذیرتر** است: مدت سفارشی، بیعانه، قوانین لغو و قیمت‌گذاری با هم کار می‌کنند.
- **بومی‌تر** است: شمسی، پیامک پترن، درگاه‌های ایرانی با Failover، ورود OTP.
- **سبک‌تر و سریع‌تر** است.
- **قابل استفاده در پروژه‌های مختلف و قابل فروش** است، با White-label و ماژول‌های قابل خاموش‌کردن.

**حوزه تخصصی ندارد.** مطب، سالن، مشاوره، باشگاه، آموزشگاه، اجاره فضا و هر کسب‌وکار «زمان‌محور» را پوشش می‌دهد. قابلیت‌های تخصصی (مثل چارت دندانی Medino) بعداً **Add-on** جداگانه خواهند بود، نه بخشی از هسته.

## 2. نقش‌ها
| نقش | نیاز اصلی |
|---|---|
| **Admin** | تنظیم کامل، گزارش، مدیریت پرسنل |
| **Manager** | مدیریت نوبت‌ها و پرسنل (محدود به شعبه‌های خودش در صورت نیاز) |
| **Receptionist** | ثبت سریع نوبت تلفنی، بدون پرداخت یا با پرداخت در محل |
| **Staff** (ارائه‌دهنده) | دیدن تقویم خودش، ثبت مرخصی، تغییر وضعیت نوبت‌هایش |
| **Customer** | رزرو، پرداخت، لغو و تغییر در پنل با ورود OTP |
| **Guest** | رزرو بدون ثبت‌نام، فقط با تأیید موبایل |

دسترسی‌ها با **Capability** مدیریت می‌شوند و نقش‌ها فقط مجموعه پیش‌فرضی از آن‌ها هستند.

## 3. زبان دامنه (Ubiquitous Language)
| اصطلاح | تعریف |
|---|---|
| **Location** | شعبه با منطقه زمانی و تقویم تعطیلات. اگر فقط یک شعبه باشد، در UI پنهان است. |
| **Staff** | ارائه‌دهنده انسانی خدمت. |
| **Resource** | منبع غیرانسانی مثل اتاق، صندلی، دستگاه یا زمین. اختیاری است. |
| **Service** | خدمت قابل رزرو. |
| **Variant** | ترکیب «مدت + قیمت» یک خدمت. Custom Duration یعنی چند Variant. |
| **Extra** | افزودنی خدمت با قیمت و مدت اضافه. |
| **Schedule** | ساعات کاری هفتگی + استراحت + استثناها (مرخصی، روز خاص) + تعطیلات. |
| **Buffer** | زمان آماده‌سازی قبل یا بعد از نوبت که به مشتری نشان داده نمی‌شود. |
| **Slot** | زمان قابل رزرو. همیشه **محاسبه** می‌شود و هیچ‌وقت ذخیره نمی‌شود. |
| **Hold** | رزرو موقت یک اسلات در حین پرداخت، با مدت انقضا. |
| **Appointment** | نوبت. |
| **Policy** | قوانین لغو، تغییر، بیعانه، تأیید دستی و بازه رزرو. |
| **Price Rule** | قانون قیمت، مثلاً «بعد از ساعت 21، 20% گران‌تر». |

## 4. دامنه نسخه 1.0 (قابل فروش)
| حوزه | قابلیت‌ها |
|---|---|
| کاتالوگ | شعبه‌ها، پرسنل، منابع، خدمات + دسته‌بندی، **Variant** (مدت سفارشی)، Extra، Buffer، **قیمت یا مدت اختصاصی هر پرسنل**، ظرفیت (رزرو گروهی ساده) |
| زمان‌بندی | برنامه هفتگی چندبازه‌ای، استراحت، مرخصی، روز خاص، **تعطیلات رسمی 1405 آماده**، حداقل فاصله تا رزرو، حداکثر رزرو آینده |
| موتور رزرو | Availability با پرسنل + منبع، **Hold و قفل تراکنشی**، حالت‌های «اولین نوبت خالی» و «تقویم و ساعت در یک نما» |
| نوبت | ماشین وضعیت، تأیید دستی، لغو، تغییر، عدم مراجعه، یادداشت داخلی، کد پیگیری |
| Policy | مهلت لغو و تغییر، **استرداد پلکانی**، **بیعانه درصدی یا ثابت**، تأیید دستی |
| قیمت | پایه، اختصاصی پرسنل، Extra، **قانون زمانی** (ساعت و روز هفته)، کوپن ساده |
| فرم | فیلدهای سفارشی برای هر خدمت (متن، عدد، انتخابی، چک‌باکس، فایل)، با شرط ساده |
| مشتری | CRM ساده (سوابق، یادداشت، برچسب)، **ورود OTP**، پنل مشتری (نوبت‌ها، لغو، تغییر، پرداخت مانده) |
| پرداخت | زرین‌پال، زیبال، پرداخت در محل، ووکامرس (اختیاری)، Failover درگاه، تطبیق خودکار، ثبت استرداد |
| اعلان | پیامک (کاوه‌نگار، IPPanel/فراز، SMS.ir، ملی‌پیامک + Failover) و ایمیل؛ تأیید، یادآوری، لغو، تغییر؛ ساعات سکوت |
| Admin | داشبورد، **تقویم** (روز با ستون پرسنل، هفته، لیست) با Drag & Drop، ثبت سریع منشی، گزارش پایه، خروجی CSV |
| نمایش | Shortcode + بلوک گوتنبرگ، ریسپانسیو، RTL، حالت تاریک، رنگ‌بندی قابل تنظیم |
| فروش‌پذیری | **White-label** (نام، لوگو، رنگ)، **ماژول‌های قابل خاموش‌کردن**، Onboarding Wizard، Site Health، ترجمه کامل fa_IR و en |

## 6. آنچه عمداً انجام نمی‌دهیم (فعلاً)
- پرونده بالینی، انبار، حسابداری کامل، اقساط و صندوق. این‌ها Add-on آینده‌اند، نه هسته.
- حالت SaaS یا چندمستأجری.
- اپ موبایل native.
- پشتیبانی ویژه از Multisite، فراتر از «هر سایت، داده جدا».

## 7. معیارهای کیفی (NFR)
| معیار | هدف |
|---|---|
| Double booking | **صفر**، با تست همزمانی در CI |
| `GET /availability` (یک روز، 10 پرسنل) | p95 کمتر از 300ms روی هاست اشتراکی |
| ویجت رزرو | JS کمتر از 40KB gz و CSS کمتر از 10KB gz |
| صفحات بدون ویجت | هیچ asset یا کوئری اضافه‌ای بارگذاری نشود |
| دسترس‌پذیری | WCAG 2.2 AA برای ویجت و پنل مشتری |
| سازگاری | PHP 8.1 تا 8.4، WP 6.6 تا 7.x، MySQL 5.7+ و MariaDB 10.4+ |
| پوشش تست | Domain حداقل 90%، کل PHP حداقل 75% |
